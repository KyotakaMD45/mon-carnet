# Mon Carnet

Carnet de crédit pour les boutiques de Côte d'Ivoire : clients, dettes, paiements (espèces, Wave, Orange Money, MTN MoMo, Moov Money), rappels WhatsApp et rapport du jour.

- Utiliser l'appli : https://kyotakamd45.github.io/mon-carnet/
- Sur Android : ouvrir le lien dans Chrome, menu ⋮, « Ajouter à l'écran d'accueil ».
- Les données restent sur le téléphone (aucun serveur). Pense à faire une sauvegarde chaque semaine dans Réglages.
